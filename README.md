# lycee-tracker

Application to track a high school (lycée) student's grades: per subject, coefficients, averages per trimester and overall.

## Planned features

- Record grades (note /20, coefficient, date, type: contrôle, DM, oral…)
- Subject averages and weighted general average
- Per-trimester view and progression over time
- Bac preparation: contrôle continu and spécialités tracking

## Privacy

Grades are personal data. They are stored locally and are **never committed** to this repository (see `.gitignore`).
